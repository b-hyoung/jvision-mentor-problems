# problem002

## 출제일
2026-04-11

## 문제 설명

정수 `N`을 입력받아, `N`줄에 걸쳐 피라미드 모양으로 별(`*`)을 출력하세요.

각 줄은 가운데 정렬되어야 하며, `i`번째 줄에는 `(2*i - 1)`개의 별이 출력됩니다.
별 앞의 공백은 `(N - i)`개입니다.

예를 들어 `N`이 3이라면 아래와 같이 출력합니다.

```text
  *
 ***
*****
```

## 입력

- 정수 1개
- `1 <= N <= 100`

## 출력

- 첫째 줄부터 `N`번째 줄까지 피라미드 형태로 별을 출력합니다.
- 각 줄의 별 앞에는 `(N - i)`개의 공백을 출력합니다.
