# problem001

## 문제 설명

정수 하나를 입력받아 그대로 출력하세요.

## 입력

- 정수 1개

## 출력

- 입력받은 정수를 그대로 출력

## 답안 위치

- `answer/problem001/{github-id}.py`

예시:

- `answer/problem001/minsu.py`

## 테스트 케이스

```json
[
  {"input": "5", "output": "5"},
  {"input": "0", "output": "0"}
]
```

## 힌트 가이드 (AI 전용)

- 입력값을 그대로 출력하는 문제임
- 오답일 경우 입력을 받는 방법과 출력 방법을 점검하도록 유도
- 절대 정답 코드를 알려주지 말 것
- 심화 테스트는 음수, 큰 수, 0 등의 엣지케이스를 생성할 것
- 엣지케이스는 3개 이내로 생성할 것
