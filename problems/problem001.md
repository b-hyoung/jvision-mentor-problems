# problem001

## 출제일
2026-04-06

## 문제 설명

정수 `N`을 입력받아, 1개부터 `N`개까지 별(`*`)을 한 줄씩 출력하세요.

예를 들어 `N`이 5라면 아래와 같이 출력합니다.

```text
*
**
***
****
*****
```

## 입력

- 정수 1개
- `1 <= N <= 100`

## 출력

- 첫째 줄부터 `N`번째 줄까지 별을 1개씩 늘려가며 출력합니다.

## 답안 위치

- `answer/problem001/{github-id}.c`

예시:

- `answer/problem001/minsu.c`

1
